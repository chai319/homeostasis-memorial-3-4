# 恒常性メモリアル 3年4組

3年4組のキャラクター原案と脚本案をもとに作った、恒常性と人との関わりを扱う学園ノベルゲームです。4月8日から6月21日までの45日と、その翌日のエピローグを遊べます。

ブラウザで「はじめる」を押し、主人公の性別、放課後の場所、休日の予定や会話を選んで進めます。画面上部には能力と、選択した「気になる人」の友好・ときめきが表示されます。この選択はメモであり、結末を固定しません。手帳には能力・週間目標・体の地図・観察メモ・関係マップ・会話・結末の記録があります。体育祭では応援合戦と騎馬戦を操作します。

## ローカルで遊ぶ

Macでは `試遊版を起動.command` を開きます。Python 3 が必要です。ほかの環境ではゲームのフォルダで `python3 -m http.server 8766 --bind 127.0.0.1` を実行し、ブラウザで `http://127.0.0.1:8766/` を開きます。

保存は、そのブラウザ・その公開先のローカルストレージを使います。ブラウザのサイトデータを消すと記録も消えます。直前の公開版の記録は、その版の物語として復元できます。新しい物語を始めて記録すると、同じ保存欄が更新されます。音楽と効果音は「設定」で音量を変えられます。

## 制作

原案：3年4組。脚本案：エモ。エンジン・画面・データ化・補完台詞・素材制作：モン（Codex）。2026-11-05、先生から既存脚本案の正式データ化・補完までの実施許可を受けて制作しました。

V4.5のエンジンを分家し、背景の一部を継承しています。人物・物語・追加の背景と一枚絵は3年4組向けに制作しました。人物の基本立ち絵と表情シート、背景39点（重ね用2点を含む）、一枚絵19点を収録しています。画像は生成素材、日常BGMの一部は takai／音楽の卵（https://ontama-m.com/ongaku.html）、残りのBGMと効果音は本作向けの自作合成音です。自作合成音はRMSとピークをそろえています（LUFS測定ではありません）。検討したOtoLogic音源は本作では使用していません。素材の生成記録・出典・ハッシュは `assets/` 内の各manifestにあります。

## 検証の範囲

- 45日間の本編画面での通し操作、途中の保存復元、体育祭の競技。
- 男女2通り×18種類の結末と手紙の組み合わせを、3画面サイズの制御状態から再生。各回3回の保存復元。
- JavaScriptで6人×5種の乱数による30周と履歴再生の一致。6人全員に、状態を書き換えず個人エンドへ届く操作方策を確認。

実機iPadは未検証です。エモ作成の独立したPython全編モデルは納品されていないため、PythonとJavaScriptの全日末状態の一致は未検証です。3年2組・3年3組のデータは参照していません。

## 設計からの調整

45日の暦・6本の会話で通常操作を模擬した結果を踏まえ、個人エンドの理解条件を8から6、ときめきによるスキ分岐を65から45へ調整しました。友好70、地図判明、能力条件とその緩和は維持しています。元の設計ファイルは変更せず、正式データの `rules.balance_revision` に記録しています。

恩師は贈り物やデートがなく自由行動の水曜も2回しかないため、台本内の恩師の友好加点を9倍、教室での遭遇を友好+2としました。段階と結末の友好条件50／70は維持しています。始業式の声の小ささを観察メモに加え、進路希望調査と合わせて2枚で推理できます。
